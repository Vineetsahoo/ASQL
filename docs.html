Detecting Full Table Scans.

One of the primary features of ASQL is detecting queries that bypass indexes. This typically occurs when utilizing wildcard searches or functions on indexed columns.

-- Anti-Pattern: Using a function on an indexed column
SELECT * FROM users WHERE LOWER(email) = 'test@example.com';

-- Optimized: Store lowercase emails or use a generated column
SELECT * FROM users WHERE email = 'test@example.com';
